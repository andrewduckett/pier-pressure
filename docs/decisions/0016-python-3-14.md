# ADR-0016: PierPressure runs on Python 3.14

## Context

PierPressure was built on Python 3.12. Since April 2025, 3.12 has received only
security fixes, not bug fixes. Python 3.14 is the newest stable release, and it
gets bug fixes until October 2027 and security fixes until October 2030.

Nothing has been released yet, so no adopter runs PierPressure today. Changing
the Python version now affects only the maintainer. After the first release it
would also affect every adopter who builds from source.

The determinism rule still applies: the same inputs must give a byte-identical
verdict document. Before this decision, the full test suite and strict type
checks were run on Python 3.14.7. Every test passed, and the golden verdict
documents did not change by a single byte.

Since #45, the Python version is set only in `.python-version`. The dev shell,
CI, the image and the release workflow all read it from there.

## Decision

PierPressure runs on Python 3.14. `.python-version` selects 3.14, and
`requires-python` in `pyproject.toml` is `>=3.14`, so 3.14 is also the oldest
Python the package supports.

## Consequences

- **Easier:** the project is on a Python that still gets bug fixes, with about
  four years of security fixes ahead.
- **Easier:** code may use 3.14 features. Ruff takes its target from
  `requires-python`, so its rules and formatting now follow 3.14.
- **Harder:** the package no longer installs on Python 3.12 or 3.13. The image
  bundles its own Python, so this affects only someone running from source.
- **Harder:** the formatter now drops the parentheses that PEP 758 makes optional
  around exception tuples. `except (ValueError, KeyError):` becomes
  `except ValueError, KeyError:`. Readers who know Python 2 may mistake this for
  the old `except Exception, name:` form, which bound a name.
- **Harder:** the release helper scripts no longer run on the runner's own
  `python3`, which is 3.12. The release job now sets up Python from
  `.python-version` before it runs them.

## Alternatives Considered

### Alternative 1: Stay on Python 3.12
- **Pros**: no change, and the widest range of Python versions can install the
  package.
- **Cons**: no bug fixes, and support ends in October 2028.
- **Why not**: nothing has shipped, so moving now costs the least it ever will.

### Alternative 2: Move to Python 3.13
- **Pros**: a smaller step, and slightly more mature.
- **Cons**: 3.13 stops getting bug fixes in October 2026, so the project would
  need another move within months.
- **Why not**: 3.14 passes every test already, so a stop at 3.13 gains nothing.

### Alternative 3: Move to Python 3.15
- **Pros**: the longest support period.
- **Cons**: 3.15 is still a release candidate in the locked nixpkgs, and some
  dependencies may not publish wheels for it yet.
- **Why not**: PierPressure should run on a stable Python. Move to 3.15 once it
  is released and its dependencies support it.
