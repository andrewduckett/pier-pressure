- 2026-10-31, tasks 2.2 and 2.3, after the code review (Gemini Argon, finding 1): the user chose an unknown state over unavailable. Home Assistant drops every attribute of an unavailable entity, so gating availability on the current hour hid `forecast`. Spec, design, brainstorm and proposal were revised to match.
