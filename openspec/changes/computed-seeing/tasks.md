## 2. Computed seeing in the core [depends-on: 1]

- [x] 2.1 [medium] A pure bad-layer count in `pierpressure/core/computed.py` counts a layer as bad when its temperature falls by less than 0.476 K per 100 m, or rises. It counts only layers whose lower height is at or above the pier's elevation and which lie below the tropopause. The tropopause is the lowest level at 500 hPa or higher up whose next level is higher, and whose temperature falls by 2 K per km or less to it. A layer whose heights don't increase upward is neither bad nor a tropopause. Cover every bad-layer and tropopause scenario in the spec (design DD4). (verify: `uv run pytest tests/test_computed.py -k bad_layer`) (✓ `uv run pytest tests/test_computed.py -k bad_layer` passed)
- [x] 2.2 [medium] `computed_seeing` gives the ADR-0033 values: 1.0 for 0 bad layers with an 80 km/h jet and a 150 m boundary layer, 0.6261 for 2, 150 and 500, and 0.1117 for 3, 250 and 900. Every value lies in `[0, 1]`. A bad layer more, a jet further outside 18 to 126 km/h, or a deeper boundary layer never raises it (design DD6). (verify: `uv run pytest tests/test_computed.py -k seeing_value`) (✓ `uv run pytest tests/test_computed.py -k seeing_value` passed)
- [x] 2.3 [medium] The computed seeing series is keyed `computed`. It covers the column's hours, blank where any member is blank, and carries the column's issue time. With a member series missing it returns `MissingColumn`, and with no full hour it returns `NoSharedHour`. The core module still imports nothing from the conditions layer or `health` (design DD4). (verify: `uv run pytest tests/test_computed.py tests/test_core_boundary.py`) (✓ `uv run pytest tests/test_computed.py tests/test_core_boundary.py` passed)
